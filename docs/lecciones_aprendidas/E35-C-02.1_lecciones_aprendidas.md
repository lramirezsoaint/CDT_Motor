# E35-C-02.1 lecciones aprendidas

- Para duplicidad en `Líneas`, el patrón más confiable es tomar la primera fila visible y repetir exactamente `Código`, `Nombre` y `Negocio`.
- La validación fuerte no es solo el mensaje; también debe confirmarse que la cantidad de filas visibles no aumente.
- Si `Estado` ya viene precargado en el modal, conviene respetarlo salvo que difiera del registro base.
