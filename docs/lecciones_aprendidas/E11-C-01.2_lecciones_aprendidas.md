# E11-C-01.2 lecciones aprendidas

- `Grupo Producto` hereda el riesgo base de `E10`: si la descarga no se completa, `E11` debe fallar por la causa real del módulo y no por una validación artificial del archivo.
- La estructura del workbook debe contrastarse con las columnas visibles de la tabla, no con una lista hardcodeada.
- El helper compartido evita duplicar la lógica de descarga y de lectura del Excel.
