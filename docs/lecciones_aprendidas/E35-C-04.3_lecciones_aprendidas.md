# E35-C-04.3 lecciones aprendidas

- El caso necesita un archivo controlado de `Canales` para poder validar el flujo completo de `Cargar Canales`.
- Mientras no exista ese archivo, el estado correcto sigue siendo `DATA`, no `TECH`.
- El spec debe quedarse implementado con el camino del caso listo para revalidarse cuando exista `REAL Canales.xlsx`.
- Lección transversal del bloque: un caso solo puede darse por correcto cuando valida su paso a paso específico y su resultado esperado propio, no una interpretación genérica del flujo de carga.
