# E35-C-03.3 lecciones aprendidas

- `Canales` es uno de los flujos más simples para validar formato y obligatoriedad en alta.
- El campo `Código` debe probarse con caracteres especiales para detectar validación de formato real y no solo bloqueo del botón.
- Si el modal mantiene el botón final deshabilitado con datos inválidos, eso también es señal útil para QA siempre que el modal no proceda.
