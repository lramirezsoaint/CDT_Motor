# E11-C-01.6 lecciones aprendidas

- `Unidades de Cuenta - BBA/VFA` tiene un toolbar distinto, así que la integridad del Excel depende primero de resolver bien la descarga del módulo.
- Aunque haya muchísimas filas visibles, si no hay archivo no debe “simularse” la validación de alteración.
- Este caso reutiliza el mismo guardarraíl de una sola ventana para no introducir ruido visual adicional.
