# E35-C-02.2 lecciones aprendidas

- En `Grupo Producto`, la duplicidad no se reproduce bien si falta `Método de Valoración`; ese campo también participa en el bloqueo de negocio.
- `Nombre Línea` sigue siendo derivado; para duplicidad basta con repetir `Código Línea` y dejar que el campo autocompletado acompañe.
- El botón `Agregar` deshabilitado puede ser una señal de regla de negocio, pero el caso debe seguir buscando el mensaje de duplicidad visible para quedar alineado al catálogo.
