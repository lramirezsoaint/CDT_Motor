# E35-C-03.1 lecciones aprendidas

- En altas negativas de `Líneas`, el botón `Agregar` puede quedar deshabilitado antes del submit; por eso la validación debe aceptar también el bloqueo de acción cuando el campo obligatorio sigue vacío.
- `Negocio` y `Estado` conviene validarlos al menos como selectores visibles, aunque la UI no siempre exponga mensaje inmediato de requerido.
- El patrón de `blur + mensaje por campo + modal sigue abierto` sirve mejor que depender de waits artificiales.
