# E35-C-02.4 lecciones aprendidas

- En `Subcanales`, la clave de duplicidad útil para QA es repetir `Código Subcanal`, `Nombre Subcanal` y `Código Canal`.
- `Nombre Canal` no hace falta llenarlo manualmente porque el sistema lo deriva desde `Código Canal`.
- El patrón `mensaje de duplicidad + filas sin cambio` se sostuvo bien también en este módulo.
