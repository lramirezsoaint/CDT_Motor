# E35-C-01.1 lecciones aprendidas

- En altas positivas de `Líneas`, el patrón estable es `Código + Nombre + Negocio + Estado`, seguido de validación de mensaje de éxito y fila visible en tabla.
- `Estado` puede venir precargado; conviene reutilizar ese valor si la UI ya lo dejó en `Activo` en vez de forzar un cambio innecesario.
- La columna `Modificado` debe validarse solo si realmente está visible en la tabla.
