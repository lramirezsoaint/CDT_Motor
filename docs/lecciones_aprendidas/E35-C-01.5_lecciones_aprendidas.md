# E35-C-01.5 lecciones aprendidas

- `Configuración de Parches` sigue siendo el flujo más sensible del bloque por la cantidad de campos opcionales y dependencias entre combos.
- La tabla puede representar `Atribuible` como `Sí/No` aunque el combobox muestre `Atribuible/No Atribuible`; esa traducción debe contemplarse en la validación.
- En la corrida actual el registro sí persiste en tabla, pero el sistema no muestra un mensaje visible de éxito después de `Agregar`; eso debe clasificarse como `BUG` funcional y no como fallo técnico del test.
- Si aparece validación previa del campo `Cuenta`, conviene normalizarlo solo para destrabar el flujo y no tocarlo cuando la UI no lo exige.
