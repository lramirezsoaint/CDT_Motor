# E35-C-01.2 lecciones aprendidas

- En `Grupo Producto`, `Código Línea` debe tratarse como combobox real y `Nombre Línea` como campo derivado no editable.
- El código del producto puede generarse de forma segura tomando el prefijo de la línea seleccionada y agregando un sufijo numérico dinámico.
- La verificación fuerte para QA es: mensaje de éxito, cierre del modal, fila visible y consistencia entre `Código Línea` y `Nombre Línea`.
