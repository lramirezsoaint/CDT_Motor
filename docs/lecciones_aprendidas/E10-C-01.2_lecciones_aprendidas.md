# E10-C-01.2 lecciones aprendidas

- `Grupo Producto` muestra un control visual de descarga, pero en la corrida actual no completó el evento de descarga.
- No se debe usar el texto completo del `body` como “mensaje del sistema”; eso ensucia el diagnóstico con contenido no funcional.
- Cuando el botón está visible y usable, pero no se genera archivo ni mensaje, la clasificación correcta es `BUG`.
- El flujo debe mantenerse en una sola ventana del contexto; abrir o dejar páginas extra complica la observación manual y genera ruido en estas validaciones de descarga.
