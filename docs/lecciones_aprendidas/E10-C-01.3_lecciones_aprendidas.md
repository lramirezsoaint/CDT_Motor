# E10-C-01.3 lecciones aprendidas

- `Canales` sigue el patrón estándar de descarga del módulo `Comunes`.
- La validación del archivo descargado debe confirmar nombre sugerido coherente con el módulo además de la existencia física del archivo.
- El helper compartido de descargas sirve bien para módulos que conservan el toolbar estándar.
- La protección de “una sola ventana” conviene vivir en el helper de descargas y no repetirse spec por spec.
