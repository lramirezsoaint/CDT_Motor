# E10-C-01.5 lecciones aprendidas

- `Maestro UoA` muestra datos y control de descarga, pero en esta corrida no materializó el archivo.
- Cuando hay data visible y la exportación no ocurre, no debe degradarse a `DATA`; corresponde `BUG`.
- El módulo mezcla botones con texto (`Cargar`, `Ver`) y un ícono de acción, así que el selector de descarga debe seguir el toolbar real del módulo.
- Esta familia de casos debe ejecutarse con una sola ventana de Playwright; si aparece otra página del contexto, debe cerrarse automáticamente.
