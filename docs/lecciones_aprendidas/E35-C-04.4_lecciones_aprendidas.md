- Después de corregir el flujo, el caso ya no falla por el modal: revela un `BUG` funcional real.
- El comportamiento actual observado es que la carga sí sobrescribe la información manual no coincidente, cuando el caso esperaba que se mantuviera y solo se actualizaran los códigos coincidentes.
