# E35-C-02.3 lecciones aprendidas

- En `Canales`, la duplicidad se valida de forma estable repitiendo `Código` y `Nombre` de la primera fila visible.
- La comprobación de no incremento de filas ayuda a distinguir entre un simple bloqueo visual y una persistencia indebida.
- Este flujo es buen candidato para smoke de reglas de negocio porque casi no depende de campos derivados.
