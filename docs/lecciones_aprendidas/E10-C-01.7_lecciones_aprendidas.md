# E10-C-01.7 lecciones aprendidas

- `Configuración de Parches` hoy puede no tener registros; el caso debe quedar implementado y clasificar ese escenario como `DATA`.
- Si el botón de descarga aparece deshabilitado junto con tabla vacía, el fallo debe reportarse como dependencia de datos, no como bug técnico.
- Conviene dejar estos casos listos para que, cuando exista data, solo cambie el resultado de ejecución y no el spec.
- Incluso en escenarios `DATA`, el caso debe mantener una sola ventana de ejecución para no confundir la revisión manual del entorno.
