# E35-C-03.5 lecciones aprendidas

- `Configuración de Parches` es el más complejo del bloque y requiere tolerancia a muchos campos opcionales y selectores.
- Las validaciones de formato útiles para QA están en `Código Concepto`, `Dígito de Cuenta`, `Cuenta` y `Porcentaje`.
- En este módulo, la obligatoriedad real más importante para alta negativa está en `UoA Antes`, `UoA Después` y `Porcentaje`.
