# E10-C-01.6 lecciones aprendidas

- `Unidades de Cuenta - BBA/VFA` tiene un toolbar diferente (`Traer PCF`, `Ver`, ícono de acción) respecto a otros módulos de `Comunes`.
- Aunque existan filas en tabla, la descarga puede no completarse; eso debe quedar como `BUG` si no hay mensaje funcional que lo explique.
- Este módulo necesita tratarse como variación de UI real y no asumirse idéntico a `Líneas` o `Canales`.
- La automatización de este lote debe cerrar cualquier página adicional del contexto y conservar una sola ventana visible durante la corrida.
