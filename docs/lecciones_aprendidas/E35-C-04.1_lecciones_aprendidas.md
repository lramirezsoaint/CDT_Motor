# E35-C-04.1 lecciones aprendidas

- El flujo real de `Cargar Líneas` no empieza directamente en el selector de archivo: primero muestra una advertencia con `Continuar con la carga` y recién después expone la etapa de examinar archivo.
- Para este caso, el resultado esperado no es una sobrescritura total. La validación correcta es:
  - aparece la alerta de reemplazo
  - el archivo actualiza los códigos coincidentes
  - la información manual no coincidente se mantiene visible
- El caso quedó `PASS` después de respetar el paso a paso real del modal.
- Lección transversal del bloque: un caso solo puede darse por correcto cuando valida su paso a paso específico y su resultado esperado propio, no una interpretación genérica del flujo de carga.
