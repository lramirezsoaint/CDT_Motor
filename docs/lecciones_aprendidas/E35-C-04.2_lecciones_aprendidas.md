# E35-C-04.2 lecciones aprendidas

- `Grupo Producto` comparte el paso previo de advertencia antes de seleccionar archivo, así que el helper de carga debía contemplar `Continuar con la carga`.
- La comparación con el archivo no debe usar columnas que el front no muestra de forma estable; se ajustó a columnas de negocio visibles.
- Tras corregir el flujo, el caso sigue `FAIL - BUG`: la carga no deja visible en tabla una fila representativa del archivo cargado, por lo que todavía no se confirma la actualización esperada por códigos coincidentes.
- Lección transversal del bloque: un caso solo puede darse por correcto cuando valida su paso a paso específico y su resultado esperado propio, no una interpretación genérica del flujo de carga.
