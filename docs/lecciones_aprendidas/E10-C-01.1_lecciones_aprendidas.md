# E10-C-01.1 lecciones aprendidas

- La descarga de `Líneas` sí emite evento real de navegador y se puede validar con `page.waitForEvent('download')`.
- El botón de descarga del flujo de `Comunes` puede ser un ícono sin texto, por lo que conviene resolverlo desde el toolbar real y no solo por label.
- Para descargas, el assert útil no es solo “se hizo click”, sino `archivo creado`, `extensión válida` y `peso > 0`.
- El caso debe forzar una sola ventana de Playwright por ejecución; si el contexto abre páginas extra, hay que cerrarlas desde un helper compartido para no contaminar la validación visual.
