# E35-C-01.4 lecciones aprendidas

- En `Subcanales`, `Código Canal` debe seleccionarse desde combobox y `Nombre Canal` debe autocompletarse automáticamente.
- El código del subcanal se puede construir dinámicamente con el prefijo del canal seleccionado más un consecutivo aleatorio para evitar colisiones.
- La validación útil para negocio es: fila creada con `Código Subcanal`, `Subcanal`, `Canal`, `Estado` y nombre de canal coherente.
