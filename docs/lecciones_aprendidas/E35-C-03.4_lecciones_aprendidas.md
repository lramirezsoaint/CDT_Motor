# E35-C-03.4 lecciones aprendidas

- `Subcanales` hereda casi todo el patrón de `Canales`, pero añade la dependencia `Código Canal` / `Nombre Canal`.
- Los campos derivados o de selector deben validarse como tales y no forzarse como textbox manual.
- Este caso se beneficia de un helper genérico de altas negativas para no duplicar localización de campos y validaciones.
