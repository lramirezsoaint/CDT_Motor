# E10-C-01.4 lecciones aprendidas

- `Subcanales` también descarga con el patrón estándar y reutiliza correctamente el helper común.
- La navegación a la vista debe confirmarse por URL y heading antes de intentar la exportación.
- Mantener un helper por comportamiento evita duplicar lógica de guardado de archivo y clasificación de errores.
- Para ejecución visible, el helper debe cerrar páginas adicionales del contexto y dejar una sola ventana activa.
